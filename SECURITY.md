# Segurança

## Versão suportada

Somente a versão mais recente publicada em Releases recebe correções.

## Como relatar

Não abra uma Issue pública contendo banco de dados, backup, log completo,
credencial, certificado ou informação operacional real. Use um aviso privado de
segurança do GitHub ou entre em contato diretamente com o responsável pelo
repositório.

Inclua apenas:

- versão do aplicativo;
- horário aproximado;
- ação realizada;
- mensagem exibida;
- trecho mínimo de log com dados pessoais removidos.

## Limites atuais

Esta é uma versão de protótipo sem assinatura Authenticode e sem integração
homologada com pagamento ou emissão fiscal. Nenhuma aprovação financeira deve
ser simulada pela interface.
